# Central Tassitani

Aplicação Node.js/MySQL. Repositório público somente do código, sem acervo ou histórico privado.

Node.js 24; build: `npm run build`; entrada: `hostinger.mjs`.

Configure no servidor: MYSQL_HOST, MYSQL_DATABASE, MYSQL_USER, MYSQL_PASSWORD, OWNER_EMAIL, MEMBERS_JSON (lista de objetos email/name), GOOGLE_CLIENT_ID, COOKIE_SECURE=true e APP_URL. Credenciais opcionais OpenAI, SMTP e Meta ficam somente no servidor.

Conecte ao banco privado existente para preservar o acervo. Imagens legadas em arquivos precisam ser migradas separadamente antes da troca de domínio.
